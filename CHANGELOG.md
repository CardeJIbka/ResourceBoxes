# Changelog

## [1.1.0] - 2025-10-14
### Added
- Copper-tier armor, weapons and tools to ArmorBox, WeaponBox and ToolBox (with adjusted drop probabilities).
- Translations for item names to Spanish (es_es), French (fr_fr), German (de_de), Chinese (zh_cn) and Japanese (ja_jp).

### Changed
- Significantly increased drop chances from loot tables for all resource boxes.
- Updated `fabric.mod.json` for explicit support of Minecraft 1.21.9 and 1.21.10.
- Branch naming convention: `1.21.9-fabric` for this release.
